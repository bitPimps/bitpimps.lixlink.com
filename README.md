# bitpimps.lixlink.com Archive

This repository serves as an **archival snapshot** of the website [bitpimps.lixlink.com](https://bitpimps.lixlink.com). It preserves the site's structure, assets, and content for reference, research, and historical purposes.

## Overview

The [bitpimps.lixlink.com](https://bitpimps.lixlink.com) website was part of the LIX Link Network — a small web experiment/community site that reflected early-2000s internet creativity, humor, and web culture. This repository captures the final public version of the site before it went offline.

The archive includes:
- Original HTML, CSS, and JavaScript files  
- Images, icons, and other static assets  
- Site metadata or configuration files (if applicable)

No active development or maintenance is performed on this version. It is preserved *as-is*, reflecting the site’s state at the time of capture.

## Purpose

This repo exists to:
- Preserve digital and web culture history  
- Provide a reference for nostalgic or educational use  
- Ensure the site remains viewable without the original host

**Total Size: ~7.4GB** (batched commits due to GitHub 2GB push limit)

## 🛠️ Tech Stack (2003-2007)
- **PHP**: phpBB forums, custom CMS
- **MySQL**: Forum + gallery database  
- **Flash**: Animations, splash screens
- **Photoshop**: Custom PSD graphics
- **Apache**: Static HTML generation
