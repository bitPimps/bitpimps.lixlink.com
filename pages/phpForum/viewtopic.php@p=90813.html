I've given the Losi a few runs around the apartment, and it handles really well, buts a bit too fast for indoors. So this is gonna be mostly an outdoor toy. This was my first run outdoors, so I sat the camera on the chair next to me to catch some of the jumping action.

I threw this vid together with Windows Movie Maker. I picked a MP3 CD at random, and found a random track that happened to be the right length, and when I threw it together, it fit as well if not better than anything I've intentionally done. Really kinda odd how that works.
