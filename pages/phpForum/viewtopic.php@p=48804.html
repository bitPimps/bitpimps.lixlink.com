But now proportional technology is getting more practical.

Here Son_Gokou turns us on to a link which points out some resistors that can be jumpered in the SE, that combined with Cyborg_Zero's voltage bypass mod, this opens up the potential for the SE, and makes it a very enjoyable cars. I'm surprised more people aren't picking up on this. If I write a clearer tutorial in layman's terms, is anybody gonna use it? Do you guys think that this would help build interest in the hobby?
