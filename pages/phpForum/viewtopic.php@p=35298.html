this is the bugger with newer MOV files using the Sorenson Quicktime codec.

In the quicktime player goto File...Export and save it as an AVI file. Then use another program (like windows movie maker in XP or something like virtualdu from www.virtualdub.org) to put into a compressed movie like Divx format for windows media format, WMV.
