I'll start with a few pics. Pretty self-explanitory. The plan is to make an awd zipzap with the same demensions of the stock zz, and all fit under a zz shell.



I'm not actually using the zz chassis. It's for referance. You can see some u-joints and, a drive shaft, and slot car gears.



The almost compleated rear end(still same wheel base as regular zz) Drive shaft, and started front end.



Also going with the awd zz, is a custom truck body. A project in itself. I've started putting in a bed allready. Yet to come is a lightbar, brushgard, and a new paint job.
