Apple makes 2 1ee7 apps called Rendesvous and Ichat AV. Rendesvous is sort of like netstumbler, in that it allows networks to be set up between 802.11x cards and base stations. It's really easy to use, and, best of all, you do'nt need a base station-just a few wifi cards. This means that, using ichat AV, which is some great software, two people in a biulding with Ibooks, small webcams, and WiFi cards, can talk to each other via WiFi.
I recall that one clever student used it to relay a copy of a test (taken with the REALLY small digital camera he used as a webcam) to another student-even as math class went on!
