The 911 uses an Xmod rear clip and a carbon fiber front clip. The rear clip screws onto an aluminum mount so that the window remains clear and untouched, 4 red LEDs have been used for the tail lights, with amber head and fog lights, one of my Scorpion light sets is tucked up under the clip so it cant be seen through the window either..

The concept doesn’t use a clip everything has been very carefully trimmed for a perfect fit, since the above photo the rear end has been lowered slightly for a better look. This body is also being outfitted with a Scorpion light set as well as some other goodies, if everything goes right you’ll see more on it in the near future.
