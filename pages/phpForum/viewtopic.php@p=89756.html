If you're going to do it on clear, I'd recommend turning it to black and white or greyscale. It will end up looking better, because with color it will all shift to blend with the color of the car. Instead of yellow flames, you'll get green; red will look purplish-black, etc. If you have photoshop, use the "multiply" blend mode to see what it will look like.
