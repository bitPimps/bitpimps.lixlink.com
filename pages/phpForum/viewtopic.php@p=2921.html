There are numerious ways to implement a computer controlled bit.

One method is to the computer's parallel port to toggle pins which are connected to the bit's transmitter. Other hardware interfaces require more logic to perform the handshaking.

One could write a software program that when certain keys are pressed, the signal drives the parallel pins, which in turn asserts the transmitters signal to drive the bit.

Since the bit's transmitters are based on GND and +5 volts, a NPN transistors works.
