Okay, So i surfed around, made sure I wasn't doing anything too noobish, like having the wrong channel selected on the controller, or not having the car turned on. But still no luck.

The stock car won't charge at all. I've tried swapping batteries between the cars, charging it turned on, charging it turned off, etc. The light on the controller flashes red for about 15 seconds, then goes orange (both red and green on at once). If I try to run it - nothing. I've tried two controllers, same results.

The DC Mod'ed one usually pulls the same trick. Every so often i will get red flashing turn into solid red - after this happens it will run but only after i turn it off and then on again, And it will only run for a really short time. I also have no reverse, although the tail lights work.

(How is charging meant to work on these anyway? Should the light go red, stay green, flash, stay solid, etc?)

I'd really like to be able to run these little fuggers because the taste I've gotten from the DC when it works has me excited. I just can't figure out the problem with either of them. Any advice would be appreciated.
