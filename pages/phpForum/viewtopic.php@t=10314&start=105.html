Post by frizzen » Thu Aug 27, 2009 2:36 pm

Yeah, that's my set. I didn't bother with the 3 duplicate body buggys. The grass is "Ready Grass" vinyl mat from the Hobby Shop train section, it's a flocked thermoset plastic so you can easily make terrain with it using like wadded newspaper and a heatgun.

One guy around here used cutdown ZZ-M springs in these. He said it helped.

I could probably pull one back open. What details do you want? just an all out exploded? I really like that the knuckles are break-away without getting into the steering box at all.

You've got 2 melt-pins at front, and 2 spring hook things at the back, lift up the steering box upper plate. *Watch springs* Next thing you see is your magnet steering rack, below that is the axle beam and the pivot it floats on, under that are the magnet coils. forward end of box has a tiny magnet on a stick for steering trim.

Rebuild in text

With an empty front end it has the coils - if you took them out have fun,
make sure the magnet-stick trim adj. is in (magnet up),
install the axle - rear end first then front make sure pivot freely,
install steering linkage - draglink type thing goes forward,
install springs on axle,
install top plate - make SURE springs align before locking down,
install knuckles,
dot of glue on melt posts at forward end of top plate.
Ride on
