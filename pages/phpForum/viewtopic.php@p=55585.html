well this is a pimp team effort, without the pimps knowing it!
payaso's se cuda with alloys looked like a smooth handling bit and he raved about it enough! so i wanted one of those, i had an se and a cuda body.
then i scored a smooth set of alloys from voodoomafia and installation was a breeze. i opted for the orange bcg gear (green zz) so i'd still have enough torque. this thing handles like a charm!
with the alloys on the cuda body didn't look right to me, so i figured i should look around for a body that was zz length but wider. i never got around to that.
a while back superfly sent me a bb shell with some other stuff and i'd always wanted to use it but they're too short for zz's.

enter mr clone bb! i used the front end of superfly's shell and the rear end of the clone to make a zz length, 4 door bb shell. slot lowered and drowned in shiny clear, this looks like the kinda ride the president would be driven around in if he had a little funk! (which he don't!)

so thanks to the pimps that contributed to this smooth talkin' 4 door , them parts has a lovin' home
