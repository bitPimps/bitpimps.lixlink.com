I'm pretty sure those are the same cars that were being sold on ebay a while back. My nephew got one, I saw it but never opened it up. All I can say is that it wasn't bad, maybe about equivalent to a first gen ZipZap performance wise. The body was pretty good, the tires were rock hard though, so if you are going to run it on a slick surface don't expect it to stick well. You might be able to scuff-in the tires with enough use??? I only played with it for a minute or two, but it seemed decent. On the plus side, what do you have to lose? Fifteen bucks isn't the end of the world if it sucks... I've payed a lot more for total crap. If you do get one why not put up a post with your impressions of the car? It might be a great find.
