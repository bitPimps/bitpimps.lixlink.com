Post by ph2t » Thu Mar 27, 2003 6:17 pm

sessiz, stay away from movie maker. It sucks some serious ballz....
It only allows you to encode in WMV formats which are really sucky as an intermediate format for editing.

my process is this:

cap from my HI-8 cam (using composite video) using FlyDS.
format 720*576, MJPEG Picvideo codec @ quality 18, 25 frames/sec (PAL settings these are, NTSC is 720 * 480, 29.97 fps)
Sound at 44.1KHz, Mono
using AVISYNTH i then resize, fix colour saturation, de-interlace, etc..

load tha puppy into virtualdub, and then I edit and compress into divx usually.

Virtualdub is good for realy simple edits, otherwise premier is great. But if you're a real hardcore puritan you'd use avisynth.

If I want to encode into wmv format use the Windows Media Encoder, not movie maker. WME allows alot of options when you are targeting a clueless audience running windoze boxen without any idea about codecs.

end rant......
