I got your pm but I'll answer it here if that's cool? I've answered a few pms like it so I'd rather put it here for others to see. First of all welcome to bitpimps. You found a great board for your zzmt crawler needs.

I don't have a complete buildup thread, just pics of pretty much completed crawlers.




This is an ok shot of the rear of one using a 3x transfer gear set up. This set up should work for you with the parts you have. You said you have 2 right? You will need to use your 2 stock green transfer gears then you can run a red transfer gear to a red drive gear and get decent gearing. You will need to pick up a motor set to get the red gears. It would be lower with all green if you can get them though but you'll need another mt to do it.

Some more pics with 3x transfer gear set up.





If you do get ahold of another mt you will be able to do this steering mod which works extremely better than the stock set up.
