Post by Sasquatch » Sat Jan 21, 2006 11:03 pm

Don't go for a FET upgrade just yet. Get used to driving it (unless you've been in R/C already) and go for some nice batteries and a motor once you're ready.

The batteries I'm using seem pretty nice to me. I haven't tested them back-to-back to other batteries, but these will do for now. I'm using the Energizer 30minute charger and the same batts that came with the charger.

If you really want more speed, go for the Kyosho X-Speed, and if thats still not enough, get someone (LHS) to do a FET upgrade and to stick the best motor they can order in.
