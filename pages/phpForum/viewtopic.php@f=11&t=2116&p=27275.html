I've read that NiMH do not develop a memory like NiCds, but they sure do seem to respond well to being 'trained' like NiCds.

Zip Zap have a 100mah NiMH, that will take up to a 5-6 minute charge from 2 AAAs. A properly charged battery will be warm. Pull it, if it starts to get hot.

Do not run your car until it stops. NiMhs like to be stored with some voltage left in them. Bits and Microsizers on the other hand have NiCds, those need to run all the way down, so the don't develop a memory.
