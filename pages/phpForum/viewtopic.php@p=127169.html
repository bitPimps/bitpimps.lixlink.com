Hey guys,

Working on a little something here, so I thought I'd share some pictures.
I built the axle myself from some scraps I had lying around, seems to be true enough at this scale to work without problems.
Steering setup is working pretty well.
The chassis snapped on me and has been re-glued together, but I think I'll end up not using it anyway.

As you can see it's pretty scruffy, shouldn't look too bad once the axle is painted black.
Just waiting on some parts so I can get started on the driveline, should be much easier than the front axle.

I have some other electronics on the way, using an old 1/10 servo for the esc as the board is small, and I've got a FM TX/RX on the way too, but at the moment it's being controled by a board and battery from a micro heli.

Enough rambling, pictures time.
