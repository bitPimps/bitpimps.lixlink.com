How To Edit HTML Copy:

<br /><br />
To create a new paragraph below the last line of copy, use two soft return HTML tags.
<br />
To create a line of copy just under the previous line, use the soft return HTML tag.
<strong></strong>
To make a word bold, the word should be surrounded by the opening and closing tags.
<em></em>
To make a word italicized, the word should be surrounded by the opening and closing tags.
<img src="Path.com" />
To make an image show on the page, use this tag and make the 'Path.com' (src="Path.com") point to the url of the image you want displayed. (i.e. <a href="http://bitpimps.lixlink.com/images/logo/bitpimps.gif" />) That would creat the image:
<a href="Path.com"></a>
To make a hyper link, the copy should be surrounded by the opening and closing tags and enter the proper attribute. Add ( target="_blank") after the (href="Path.com") to make the link open in a new window.
&copy;
Used to create the copyright symbol. (©)
&reg;
Used to create the registered symbol. (®)
&#8482;
Used to create the trade-mark symbol. (™)
